Seating Reservation Management System
A Django-based web application developed to manage guest seating assignments for a large event. Guests authenticate using reservation information, view available tables and seats, select seats for their party, modify selections, and confirm their final assignments.

Tech Stack: Python, Django, PostgreSQL, HTML/CSS, Django ORM

Key Features
- Reservation-based guest authentication
- Interactive table and seat selection
- Real-time seat availability
- Guest-count validation
- Prevention of conflicting seat assignments
- Seat modification and confirmation
- PostgreSQL relational data model
- Email confirmation (once we finish it)
